# Consumer Review Helper — Android
A generic Android app for drafting and managing authentic consumer reviews. No personal data or merchant-specific content is included. Review submission is manual through the user's normal browser. The app does not submit reviews, create accounts, collect credentials or manipulate rankings.

Build locally using Android Studio (SDK 35, JDK 17), or use the Build Android APK workflow in GitHub Actions. Download the debug APK artifact from a successful build. Debug builds are for testing, not Play Store distribution. GitHub-hosted builds are subject to account limits.

Local device testing is required before relying on the app.
